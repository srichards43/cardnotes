# Card Notes
Notes app that allows user to create collections of cards to be categorised. All data is stored via local storage and tied to the browser, but can be exported into JSON for backups or transfers. 
Assuming a local storage limit of 5MB and an average note consisting of a 20 character title and 100 character contents, a user would be able to store up to ~9500 notes.

## Features
- Drag and drop cards to change order or swap between sections
- Customisation with note colour and theme options
- Import and export data to transfer across browsers or make backups
